# Descriptive Topic Title

- Kind: investigation | plan | decision | handoff
- Status: draft | active | blocked | resolved | superseded
- Created: YYYY-MM-DD
- Last verified: YYYY-MM-DD
- Scope: affected package and components
- Evidence baseline: branch/commit and relevant local changes
- Related: canonical notes, issues, historical evidence, or replacement links

## Context and objective

State the intended outcome and boundaries.

## Verified findings

Include repository-relative paths, source symbols, commit IDs, or reproducible sanitized evidence. Distinguish historical measurements from current verified facts.

## Hypotheses and open questions

Label unverified explanations and the evidence needed to resolve them.

## Decision or implementation plan

Record the chosen approach, reasons, compatibility/version impact, and meaningful alternatives. Mark proposals as pending until accepted.

## Verification

Record commands actually run, working directory, results, environment when relevant, and limitations. List unrun checks separately. Never include credentials or private production data.

## Handoff and next actions

List remaining work, blockers, responsible files, published references if applicable, and completion checks. Link canonical notes updated with durable findings.
